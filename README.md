# MIBA College Team Project

This repository contains a simple website inspired by the structure and design of the **Software Engineering GitHub Project**.  
It is built entirely with **HTML, CSS, and JavaScript**, making it lightweight, easy to deploy, and perfect for GitHub Pages hosting.

---

## 🌟 Project Overview
Our project demonstrates the fundamentals of front-end web development while showcasing our team members and their passions in the field of technology.  
The website includes:
- A clean and modern navigation bar
- An "About" section describing the purpose of the project
- A "Team" section highlighting each member’s role and passion
- A "Contact" section with a simple form for visitors to reach out
- Responsive design principles for better viewing across devices

## ⚙️ Technologies Used
- **HTML5** → For structuring the content of the website  
- **CSS3** → For styling, layout, and responsive design  
- **JavaScript (ES6)** → For interactivity (form handling, alerts, theme toggles, etc.)

---

## 🚀 Features
- **Responsive Layout**: Works across desktop and mobile devices  
- **Team Showcase**: Highlights each member’s passion and role  
- **Contact Form**: Allows visitors to send messages (currently handled with a simple JavaScript alert)  
- **Clean Design**: Inspired by modern portfolio websites
